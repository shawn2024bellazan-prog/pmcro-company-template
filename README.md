# pmcro-company-template

The minimal **PMCR-O cognitive-loop authoring template**, built from the existing `pmcro` and `pmcro-orchestrator` plugins in [pmcro-marketplace-skills](https://github.com/shawn2024bellazan-prog/pmcro-marketplace-skills).

Authoritative source: `AGENTS.md` + `plugins/` (the dotnet/skills convention). Native `.pmcro/` is a **generated managed projection**; optional packs install separately.

## Source snapshot
Bundled plugin files are preserved verbatim from upstream commit `9093b91df2527a7fbb0d390e90b8d04775077587`. They cover the five PMCR-O core phase skills and two high-level-goal skills. This source bootstrap is **not** evidence of a native PMCR-O invocation or a completed `/init`.

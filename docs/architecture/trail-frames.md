# Trail Frames

Frames capture cycle, sequence, timestamp, actor, type, summary, structured data, and optional correction linkage. Corrections should append new frames, not rewrite prior observations. Keep secrets and unnecessary personal data out of trails. Distinguish observations, proposed lessons, validated lessons, and approved policy.

The included JSONL store sequences writes within one process. It is not cryptographically tamper-proof and does not guarantee multi-process concurrency safety.
